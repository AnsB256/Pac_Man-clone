# Pac_Man-clone-
A classic arcade Pac-Man clone featuring faithful mechanics, ghost AI behaviors, and retro-style gameplay.

- `/home/runner/work/Pac_Man-clone-/Pac_Man-clone-/src/render/mazeRenderer.js`

### Included in this step

- Fixed-step game loop boilerplate with delta-time update calls.
- Shared constants for tile size, board dimensions, and full game states.
- Maze matrix module with defensive dimension validation.
- Basic canvas renderer to visualize walls, dots, and power pellets.

### Run locally

Open `index.html` in a browser to view the initial maze and loop state render.
