# Retro Pac-Man Clone

A faithful recreation of the classic arcade game built from scratch. Navigate the maze, gobble up dots and power pellets, and avoid the colorful ghosts—each with their own unique chasing behaviors!

## ✨ Features

* **Classic Arcade Gameplay:** Eat all the dots to clear the level while dodging four distinct ghosts (Blinky, Pinky, Inky, and Clyde).
* **Power Pellets & Scared Ghosts:** Consume power pellets to turn the ghosts blue and vulnerable for a limited time.
* **Score & High Score Tracking:** Keep track of your current score, lives remaining, and saved high score.
* **Custom Ghost AI:** Basic pathfinding and scatter/chase state behaviors for authentic arcade challenge.
* **Retro Aesthetics:** Pixel-art graphics and sound effects inspired by the original 1980s cabinet.

## 🕹️ Controls

| Key | Action |
| :--- | :--- |
| **Arrow Keys / W, A, S, D** | Move Pac-Man (Up, Left, Down, Right) |
| **P** | Pause Game |
| **Esc / Q** | Quit to Menu |
